# 💻 Code Editor for HTML, CSS, & JS
A fully responsive, single-page web-based code editor designed to let users write and preview HTML, CSS, and JavaScript instantly in real-time.

--- 

## 🚀 Features

*   **Live Preview:** Write code and see the visual output instantly on a single page—no tab-switching required.
*   **Focus Mode:** Enlarge a specific language editor to focus entirely on HTML, CSS, or JS.
*   **Interactive Layout:** Fully resizable output area to test your designs across different dimensions.
*   **Modern Syntax Highlighting:** Beautifully color-coded syntax powered by `highlight.js`.
*   **Fully Responsive:** Code comfortably on desktops, tablets, or mobile screens.
*   **Attractive UI:** Sleek, modern, and dark-mode friendly design.

---

## 🛠️ Tech Stack & Libraries

*   **Frontend:** React, JavaScript (ES6+), CSS3
*   **Syntax Highlighting:** `highlight.js` (NPM Package)

## ⚙️ How to Run This Project Locally
Follow these simple steps to set up the code editor on your local machine:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your system.

### Installation & Setup
```bash
# Clone the repository
git clone https://github.com/tanishkaagarg613/code-editor-for-html-css-js

# Navigate into the project directory
cd code-editor-for-html-css-js

# Install dependencies
npm install

# Start the development server
npm start

# Open http://localhost:3000 in your browser to view the application.
```
